# Git and GitHub Assignment

## Introduction

This project is created to practice using Git and GitHub. It demonstrates the basic concepts of version control and how to manage project files.

## What is Git?

Git is a version control system that helps developers track changes in their code, save different versions, and work on projects efficiently.

## What is GitHub?

GitHub is an online platform that allows developers to store their Git repositories, share code, and collaborate with other people.

## Project Files

* `sample_data.py` — A simple Python BMI Calculator.
* `README.md` — Provides information about this project.

## Git Commands Used

* `git init` — Initializes a Git repository.
* `git add` — Adds files to the staging area.
* `git commit` — Saves changes to the repository.
* `git push` — Uploads changes to GitHub.
* `git log --oneline` — Displays the commit history.

## Conclusion

Through this project, I learned how to create a Git repository, track changes, make commits, and upload files to GitHub.
